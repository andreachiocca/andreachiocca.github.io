> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive bilingual Laboratory page that presents genuine photographs, current and historically documented fatigue-testing facilities, and verified scientific specifications in the established Technical Editorial design.

**Architecture:** Keep `_pages/laboratory.md` as the only canonical page, with Italian output generated by the existing Jekyll localization plugin. Extend `_data/laboratory.json` with structured equipment and media records, add paired `_data/i18n/it/laboratory.json` translations, a single dedicated equipment include and scoped Sass, and commit locally optimized images under `assets/img/laboratory/`. Preserve the existing research links, instrumentation contexts, collaboration contact and acceptance gates. The website remains static and requires no new runtime JavaScript, plugins or remote image service.

**Tech Stack:** Jekyll, Liquid, Sass, Python 3.11 standard library for testing, existing Chromium browser checks, Pillow for **local authoring only**, GitHub Actions and Cloudflare Pages.

**Spec:** [Approved Phase 5 Laboratory editorial design](../specs/2026-10-22-laboratory-editorial-design.md)

## Global Constraints

- Maintain the current homepage, Research Atlas, Publications, academic writing voice, theme behavior and EN/IT routing. Do not redesign global navigation, `resource_card.html`, bibliography or other pages.
- Use authentic photographs uploaded by the user, **not** generated imagery, third-party images or technical plots presented as experimental results.
- Preserve legacy Laboratory anchors `#research-expertise`, `#instrumentation` and `#laboratory-collaboration`. Add `#equipment` once verified equipment records are present.
- Keep `_data/laboratory.json` as the sole source of equipment identities, values and ordering. Its existing `capabilities` and `measurement_context` arrays and their links must not be deleted.
- Carry machine limits exactly: primary StepLab **33 kN static, 43.5 kN dynamic, ≤250 Hz (mode/specimen dependent)**; Schenck **250 kN axial, 2000 N·m torsion, internal pressure 700 bar (70 MPa)** for tubular specimens; small StepLab **10 kN, 20 Hz**; climatic chamber **−30 to +180 °C**, induction oven **up to 900 °C** and resistance oven **200–1000 °C**.
- Historical facilities listed on the Machine Design Group website are historically correct, **not** proof of a current inventory. Keep MTS **25 and 100 kN**, Rumul **20 and 150 kN** with historical typical **100–150 Hz**, and historical bench capability **up to seven actuators** separate from the user's currently described **three-Schenck-actuator** bench. Never assign a 20 or 150 kN label to the photographed Rumul without confirmation.
- FLIR is **X6901sc InSb, not X6901sc SLS**. Manufacturer datasheet supports **640 × 512**, **3–5 µm**, **up to 1004 full-frame images/s**, **NETD ≤20 mK**, **14-bit**, and **−20 to 350 °C** with appropriate optics. Do not claim those performance bounds are validated for every lab acquisition, or that optional filters, thermoelastic or lock-in techniques are installed.
- **Never publish `IMG_0420.JPG`**, the camera serial-number label photograph. It is source evidence only and must not enter Git, `_site`, image manifests, page text, captions, or pull-request screenshots.
- Crop conservatively, preserve accurate machine identity, never erase safety markings, and do not identify `IMG_3200.jpeg` as the main versus smaller StepLab until established. If uncertain, caption it **StepLab testing equipment**, not a specific model.
- Use concise, technically accurate academic EN/IT descriptions via `andrea-chiocca-academic-writing`; collective voice for group-owned facilities; preserve institutional names and original contact.
- Responsive images must have localized alt/captions, dimension attributes, WebP `srcset`, no layout shift and lazy loading outside the hero. No client-side image gallery library.
- Run the existing unit, Jekyll, locale, site, Research and Publications checks and the new focused Laboratory checks in both build/preview workflows using their **existing verification entry points**. Draft PR #33 stays unmerged until the owner approves the EN/IT Cloudflare previews.

## Review Focus

1. **Pressure/units and coupled limits.** Given Italian or English rendering, Schenck must show exactly `700 bar`, must not show `700 MPa`, and must not suggest all force, torque, frequency and pressure maxima occur together. Pin in Task 1 source tests and Task 4 generated-site tests.
2. **Historical versus current equipment.** Given the Rumul 20/150 kN pair and seven-actuator historical bench alongside the new three-actuator description, headings and captions must not falsely assert every past system is currently available. Pin in Task 1 data assertions, Task 3 copy checks and Task 4 EN/IT checks.
3. **Image identity/privacy.** Given `IMG_3200.jpeg` without a confirmed model subtype, show generic StepLab wording. Given `IMG_0420.JPG`, neither its contents nor a serial number may ship. Check photo manifest and Git diff in Task 2 and linked public assets in Task 4.
4. **Missing or mislocalized image.** If one media record has no optimized file, empty alt or an incorrectly localized asset URL, fail verification before preview. Check Task 2 asset tests, Task 3 rendered-markup tests and Task 4 HTML/link tests.
5. **Mobile and static fallback.** On a narrow screen or with JavaScript disabled, all equipment values and the cooperation contact remain readable, images stack without overflow, and the hero does not shift layout. Pin to Task 3 Sass and Task 4 Chromium/HTML checks.

### Stable data contract

`_data/laboratory.json.equipment` is a list of records with:

- `id: string`, `category: "featured" | "supporting"`, `evidence_scope: "current-description" | "historical" | "manufacturer"`, `title: string` and `description: string`.
- `specifications: [{ "label": "<existing or new EN UI translation key>", "value": "<number and scientific unit>" }]`. All values remain canonical and untranslated, including 700 bar, 70 MPa and FLIR model number. Render labels with `| t` rather than overriding `specifications`, which the current locale verifier treats as immutable.
- Optional `image: { "base": "assets/img/laboratory/<slug>", "width": <original aspect-ratio width>, "height": <original aspect-ratio height> }`, using the derived 640/1280 WebP files. Alt/caption live in `image_alt` and `image_caption` and can be localized.
- Optional `notes` or `status_note` for operating conditions, current/historical qualifications. Any textual key added must be localized when user-visible, and records with `description` must always render it in both languages to satisfy `verify_languages.py`.

Required stable IDs: `steplab-axial-torsional`, `schenck-axial-torsional`, `rumul-resonant`, `mts-uniaxial`, `steplab-electromechanical`, `three-actuator-bench`, `vibration-testing`, `environmental-conditioning`, `specimen-preparation-metrology`, `flir-x6901sc`. Keep `capabilities` and `measurement_context` IDs unchanged. Do not duplicate the climatic chamber in separate equipment entries.

**Image mapping** (verify against originals before cropping): `IMG_3207.jpeg` → `specimen` hero; `IMG_0167.JPG` → `structural-bench`; `IMG_3186.jpeg` → `schenck-actuators` only when equipment identity is clear; `IMG_3200.jpeg` → `steplab-equipment` with neutral caption; `IMG_3189.jpeg` → `rumul`; `IMG_0418.JPG` → `flir-x6901sc`; optional `IMG_8745.JPG` → `vibration-setup`. Alternate `IMG_3209.jpeg` is not used simultaneously with hero `IMG_3207.jpeg`. Confirm correct cropped subject. `IMG_0420.JPG` is forbidden.
