# Retired Notes source

The three original articles are preserved here without changes for possible future reuse. The entire `docs/` directory is excluded from the Jekyll build; these files are not public posts, a collection or a download catalogue.

The former catalogue, year/tag archives and three article URLs are recorded in `_data/retired_notes_urls.json`. A small native Jekyll generator renders non-indexed redirects to Research using `_layouts/retired-notes.html`. They are excluded from the sitemap and provide a normal link if refresh is unavailable. No article text is republished. The empty legacy Atom feed remains available to existing subscribers but is no longer advertised.

The old Distill layout, catalogue interface, dedicated stylesheet and scientific-content script remain recoverable through Git history. Reusing an article requires an explicit editorial decision and a new suitable public location; do not move these files back into `_posts/` automatically.
